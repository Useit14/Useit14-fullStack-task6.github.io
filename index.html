Задание 6: производительность (на базе задания 4)

Четыре варианта одной страницы Fudi для замера DOMContentLoaded и load.

Варианты

1. Desktop + CSS — только десктоп, скомпилированный CSS
2. Adaptive + CSS — адаптив, скомпилированный CSS
3. Desktop + LESS — только десктоп, клиентский less.js
4. Adaptive + LESS — адаптив, клиентский less.js
Замеры выполнены локально (Live Server). Значение load через Navigation Timing на локальном сервере часто даёт 0 — поэтому в таблице приведено время DOMContentLoaded (формирование DOM-дерева). Для LESS дополнительно зафиксировано время клиентской компиляции из консоли less.js.

Таблица результатов

Вариант DOMContentLoaded, мс Компиляция LESS, мс Примечание
1. Desktop + CSS 95.4 — Самый быстрый вариант
2. Adaptive + CSS 140.8 — +45 мс к десктопу из‑за медиазапросов и большего CSS
3. Desktop + LESS (client) 209.6 35 Самый медленный: загрузка less.js + компиляция
4. Adaptive + LESS (client) 140.1 46 less.js уже в кэше CDN после предыдущего замера

Выводы

  • Влияние адаптивной вёрстки (медиазапросы). Адаптивная версия с готовым CSS формирует DOM дольше десктопной (140.8 мс против 95.4 мс, разница ≈ 45 мс). Причина — больший объём CSS и дополнительные правила @media, которые браузер разбирает при построении CSSOM. Влияние есть, но оно умеренное.
  • Влияние клиентского препроцессора (less.js). Подключение LESS на стороне клиента заметно замедляет страницу. Десктоп + LESS: 209.6 мс против 95.4 мс у готового CSS (примерно в 2 раза медленнее). В консоли less.js фиксирует 35–46 мс на саму компиляцию; остальное — загрузка библиотеки less.js с CDN и применение стилей. Если less.js уже в кэше (как в замере adaptive-less), разница с готовым CSS почти исчезает.
  • Общий вывод о производительности интерфейса. Для продакшена стили нужно компилировать заранее (build-step) и отдавать готовый CSS — клиентский препроцессор увеличивает время до интерактивности и зависит от сети/кэша. Адаптивная вёрстка даёт небольшой, но измеримый оверхед по сравнению с чисто десктопной. Оптимальный вариант с точки зрения скорости: скомпилированный CSS; наличие медиазапросов приемлемо, клиентский LESS — нет.
