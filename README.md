# Задание 6 — сравнение производительности (DOM / load)

Четыре статических варианта страницы Fudi (из задания 4) для замера скорости формирования DOM-дерева и отображения страницы.

## Структура

```
task6/
├── index.html          # меню + таблица для результатов
├── README.md
├── desktop-css/        # десктоп, скомпилированный CSS
├── adaptive-css/       # адаптив, скомпилированный CSS
├── desktop-less/       # десктоп, .less + less.js (CDN)
└── adaptive-less/      # адаптив, .less + less.js (CDN)
```

## Как проводились замеры

1. Режим инкогнито, расширения отключены.
2. Жёсткое обновление (Ctrl+Shift+R) перед каждым замером.
3. Смотрелись значения в нижней панели на странице (или в Console).

## Что сравнивалось

| Фактор            | Desktop vs Adaptive | CSS vs LESS (client) |
| ----------------- | ------------------- | -------------------- |
| Медиазапросы      | без / с `@media`    | —                    |
| Компиляция стилей | заранее (build)     | в браузере (less.js) |
